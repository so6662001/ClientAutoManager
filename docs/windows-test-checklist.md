# 普讯科技应用管家 · Windows 真机测试清单

> 适用于 `dist/win-x64/PuxunAppManager.exe`（自包含单文件，目标机无需安装 .NET）。
> 测试机：Windows 10/11 x64。建议先在一台测试机上验证，确认无误后再签名分发。

---

## 0. 准备

- [ ] 将 `PuxunAppManager.exe` 拷贝到测试机任意目录（如 `D:\pxtest\`）。
- [ ] 首次运行可能被 SmartScreen/杀软拦截（因未签名）——这是预期现象，正式分发前需代码签名。临时测试可点「仍要运行」或临时加信任。
- [ ] 双击运行，确认主窗口正常打开、中文显示正常、深/浅主题切换正常（右上角月亮图标）。

> 配置与日志位置：`%AppData%\PuxunAppManager\`
> - `config.json`（后端地址等）
> - `paper-types.json`（纸型类别/等份元数据）
> - `logs\app-*.log`（运行日志，排错用）

---

## 1. 客户端检测/安装模块

> 该模块需要连接你们后端。未配置后端时会显示"未连接/使用缓存/检测错误"，属正常。

- [ ] 在「设置」里填入后端 BaseUrl 与鉴权（若有），保存。
- [ ] 点「重新检测」，确认能拉到产品清单并显示状态徽章（未安装/最新/可更新/已损坏）。
- [ ] 对「未安装」项点「安装」：弹一次 UAC → 下载→校验→静默安装→状态刷新为"已安装(最新)"。
- [ ] 对「可更新」项点「更新」；对「已损坏」项点「修复」。
- [ ] 断网后点「重新检测」：确认降级为"离线/使用本地缓存清单"，不崩溃。
- [ ] 搜索框过滤、状态筛选标签（全部/未安装/可更新/已损坏）工作正常。

> 注：安装包必须是**已签名**的真实安装包，否则签名校验会拦截（这是设计行为）。

## 2. 纸型管理模块（本次新增，重点测试）

入口：主界面工具栏「🖨 纸型管理」按钮。

### 2.1 新增 — 一式二等份
- [ ] 选「一式二等份」，名称填「收银小票二联」，宽 210，高 140。
- [ ] 确认蓝色提示显示："注册为整张纸尺寸 210 × 140 mm，按 2 等份切分，每份 210 × 70 mm"。
- [ ] 点「添加」→ 弹出 **UAC**，点「是」。
- [ ] 确认下方「已存在纸型」列表出现该项，类别=一式二等份，等份=2，每份高=70。
- [ ] 打开 Windows「控制面板 → 设备和打印机 → (任意打印机)打印服务器属性 → 表单」，确认「收银小票二联」已出现且尺寸 210×140 mm。

### 2.2 新增 — 一式三等份
- [ ] 选「一式三等份」，名称「增值税三联」，宽 241，高 280 → 提示每份 ≈ 93.3 mm → 添加（UAC）。
- [ ] 列表出现，等份=3，每份高=93.3。

### 2.3 新增 — 自定义（含边距）
- [ ] 选「自定义」，名称「出库单」，宽 190，高 120，设置上/下/左/右边距各 5 → 添加（UAC）。
- [ ] 列表出现，类别=自定义。

### 2.4 判重（核心，先名称、再尺寸）
- [ ] **名称重复**：再次用名称「收银小票二联」添加（尺寸随意）→ 不弹 UAC，就地红字提示"纸型「收银小票二联」已存在，不予添加。"。
- [ ] **尺寸重复**：名称改为「小票二联备用」，类别一式二等份，宽 210 高 140 → 红字提示"已存在相同尺寸的纸型「收银小票二联」(210×140，2 等份)，不予添加。"。
- [ ] **不算重复**：把等份数/类别改不同（如三等份 210×140）→ 可正常添加。

### 2.5 编辑
- [ ] 点某自建纸型「编辑」→ 数据回填到上方表单，按钮变「保存修改」，出现「取消编辑」。
- [ ] 改高度后「保存修改」→ UAC → 列表刷新为新尺寸。
- [ ] 改名为一个**已存在**的别的纸型名 → 红字拦截（判重排除自身但仍拦别人）。
- [ ] 「取消编辑」恢复为新增态。

### 2.6 删除
- [ ] 点自建纸型「删除」→ UAC → 列表移除；打印服务器表单里同步消失。

### 2.7 系统内置保护
- [ ] 列表中 A4/Letter 等系统内置项显示「内置不可改/删」，无编辑/删除按钮。

### 2.8 权限与异常
- [ ] 增/改/删时在 UAC 弹窗点「否」→ 提示"需要管理员权限才能修改纸型（已取消）"，列表不变，可重试。
- [ ] 名称含非法字符（如 `a/b`）、宽或高填 0、边距之和≥纸张尺寸 → 红字拦截，不弹 UAC。

## 3. 收尾检查

- [ ] 关窗口时若有安装任务进行中，弹"确认退出"。
- [ ] 查看 `%AppData%\PuxunAppManager\logs\` 日志，确认操作均有记录、无异常堆栈。
- [ ] 确认 `paper-types.json` 内记录了自建纸型的类别与等份数。

---

## 4. 已知前提 / 排错

- 未签名导致 SmartScreen/杀软告警属预期；正式分发务必先 `build\sign.ps1` 签名 + 提交白名单。
- 纸型增/改/删必须管理员权限（UAC），这是 Windows 机器级表单的硬性要求。
- 若「纸型管理」打不开或写入失败：检查"Print Spooler(打印后台)"服务是否运行（`services.msc`）。
- 该 EXE 为 Linux 交叉发布版用于功能测试；如遇异常，请回传 `logs\app-*.log` 以便定位。
